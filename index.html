Machine learning for QCD: small-\(x\) evolution and hadronization.

I'm a fourth-year Ph.D. candidate in physics at Southern Methodist University in Dallas, advised by Fredrick Olness. From November 2026 to April 2027 I'm in residence at the University of Cincinnati as an NSF MCgen Fellow, one of four fellows selected nationwide, working with Jure Zupan, Manuel Szewc and Philip Ilten.

A lot of particle and nuclear physics runs an expensive calculation inside a loop that keeps changing its parameters: a global fit, a generator tune, an uncertainty scan. My work makes that parameter dependence cheap. For small-\(x\) physics I train neural surrogates for the Balitsky-Kovchegov equation, so a global analysis of HERA and future Electron-Ion Collider data can call it millions of times. For hadronization I learn per-history weights that let the flavor parameters of PYTHIA's Lund string model be changed on event samples that already exist.

Before SMU I studied computational physics at the University of the Punjab and physics at LUMS in Lahore, where I also spent four years as a teaching assistant. In 2019 I was selected to attend the 69th Lindau Nobel Laureate Meeting, which was dedicated to physics.

Research

Neural surrogates for small-\(x\) evolution

SURGE Topical Collaboration, since 2023 · with Fredrick Olness (SMU)

At small Bjorken-\(x\) the gluon density in a proton or nucleus keeps growing until nonlinear effects tame it. The running-coupling Balitsky-Kovchegov (rcBK) equation describes this through the dipole amplitude \(N(\eta, r)\). One numerical evolution takes minutes, and a global fit can need around \(10^6\) of them. I build neural networks that stand in for the solver inside the fit loop.

  1. rcBK / bkEval solver
  2. training grid ~80 GB
  3. MLP · DeepONet ~10 MB
  4. global \(\chi^2\) fit
Inputs
\(\{\eta,\ \log_{10} r,\ \gamma,\ C,\ Q_{s0}^2\}\), with an MV\(_\gamma\) initial condition and running coupling.
Speed
About 1 ms per grid point, smooth and differentiable, so gradient-based \(\chi^2\) minimization works on it directly.
Accuracy
The MLP reproduces \(F_2\), \(F_L\) and the reduced cross section to about 2% or better.
Architectures
An MLP for grid-wise prediction, and a DeepONet that evaluates at arbitrary points off the training grid.

Next: integrating the surrogate with xFitter, adding NLO terms to the evolution, and trying a JIMWLK approach.

Flavor in string hadronization (Shomer)

NSF MCgen Fellowship, University of Cincinnati · with Jure Zupan, Manuel Szewc and Philip Ilten

PYTHIA turns quarks and gluons into hadrons with the Lund string model, where a few hand-tuned parameters decide which flavors appear each time a string breaks. The MLhad collaboration's HOMER method reweights string fragmentation histories, so model parameters can be changed after the events exist. Shomer (HOMER plus sabor, flavor) extends that idea to flavor selection.

  1. PYTHIA 8 Lund string
  2. fragmentation histories
  3. learned weight w(h)
  4. reweighted observables
What is learned
The kinematic fragmentation function stays frozen. Only the flavor selector is learned: strangeness suppression, the vector-to-pseudoscalar ratio and diquark suppression.
Why weights
Swapping a pion for a kaon changes a mass, and with it the kinematics of the whole event. So the network assigns a weight to each history, and only observable-level distributions have to match data.
First stage
Quark-antiquark strings with gluons removed, so any mismatch can be traced to flavor rather than kinematics.
Diagnostics
Effective sample size \(N_{\mathrm{eff}} = (\sum_i w_i)^2 / \sum_i w_i^2\), plus classifier AUC from calibrated scores.

Other work

LHAPDF interpolation benchmark

Measures what a PDF lookup costs by access pattern, and what accuracy you lose by thinning the grid. On CT18NLO, dropping every second \(x\) node halves the file with a median error of \(2.7\times10^{-6}\). The worst cases sit exactly where the \(x\)-grid spacing changes.
